## 一、坐标对齐(新能力,已验证可行)

视觉对比已确认 r6calls 图片与官方蓝图是**同一幅渲染**,只是裁剪范围不同(r6calls 紧贴建筑,官方带周边+图例)。因此坐标可自动对齐:

1. `tools/fetch_r6calls_imgs.py`:补齐下载 r6calls 楼层图(jsdelivr,断点重试)
2. `tools/align_coords.py`:逐图逐层做图像互相关(降采样灰度、粗网格搜索偏移,scale 优先按 官方宽/floor.width)求出 r6calls→官方 的 (scale,dx,dy);按公式 `官方px = (label - floor偏移)*scale + d` 把 roomLabels 换算成归一化 x/y,写入 `data/callouts/*.json` 条目;生成叠加验证拼图
3. 我目视验证全部 20 图叠加效果;个别不齐的楼层用手动偏移表 `data/align_fixups.json` 修正;仍不齐的该层坐标置空(该层报点不上图,数据保留)

## 三、统一交互(数据点与用户点同根同源)

**三种交互,严格执行:**
- **单击**:显示坐标读数(现状),不创建任何东西
- **双击空白**:新建标注;**双击任意点(含数据点)**:改名对话框
- **拖拽**:仅放大(s>1)后可抓取平移地图;拖拽任意点=微调位置
- 点的 × 删除、命名对话框、Enter 保存等沿用
- 浏览器默认拖拽保持禁用(dragstart 阻断 + 仅鼠标 preventDefault + touch-action:none)

**覆盖层存储**(localStorage `r6pins:<map>`,内存降级保留):
```json
{ "overrides": {"<pinId>": {"zh","en","x","y","deleted"}},
  "custom": [{"x","y","en","zh"}] }
```
数据点渲染 = 文件基础 + overrides 应用(改名/移位/删除);用户自建点进 custom。pinId 由构建期生成(floor+en 派生),语言切换全量重渲染。

**齿轮设置(右下角,低调)**:小图标按钮 → 弹出面板:导出(本图全部 overrides+custom 为 JSON,可复制)、导入(粘贴 JSON 合并校验)、清空本图标注。
