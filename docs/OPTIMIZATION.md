## 二、维护规范

- **命名单一来源**:地图名(`name_en/name_zh`)、楼层名(`floor_names`)、全部界面文案(`ui` 节)都在 `data/floors.json`;模板与 JS 均不硬编码(JS 通过 `#uiTerms` JSON 注入读取)。改文案/改地名只动这一个文件。
- **构建即校验**:楼层 key 合法性、图片存在性、地图重名、报点 `en` 键完整性在 `tools/build.py` 构建期强制,错误会阻止构建而非静默上线。
- **蓝图同步**:每赛季跑 `python tools/fetch_blueprints.py --check` 对哈希;新图在 `floors.json` 增加条目后完整模式入库。
